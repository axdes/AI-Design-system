# Task: pay statement detail screen

Build the detail screen for a single pay statement.

Requirements:

- A page title with the statement period, a back affordance, and a download
  action.
- A side panel with the statement's meta: pay date, method, net amount.
- The body shows the earnings breakdown as a table (line, amount), with the
  status of the statement visible as a chip next to the title.

Deliverable: a single file `Screen.tsx` exporting `Screen()` — no props, no
router, sample data inline. Follow the project's design-system rules
(`AGENTS.md`, `component-index.md`).
