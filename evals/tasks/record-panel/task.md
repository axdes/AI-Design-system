# Task: project detail side panel

Build the right-hand detail panel for a project.

Requirements:

- A read-only block of the project's metadata: owner, status, due date, budget.
- The team on the project, shown as a stack of overlapping avatars with a
  "+N" overflow when there are more than a few.
- A recent-activity feed as a vertical timeline of dated events.

Deliverable: a single file `Screen.tsx` exporting `Screen()` — no props, no
router, sample data inline. Follow the project's design-system rules
(`AGENTS.md`, `component-index.md`).
