# Task: invoices table with sort and paging

Build an invoices table screen.

Requirements:

- Columns: invoice number, client, amount, status. The amount column sorts when
  its header is activated (toggling ascending / descending).
- The list is long, so show one page at a time with a pager below the table.
- Above the table, a breadcrumb trail: Billing / Invoices.

Deliverable: a single file `Screen.tsx` exporting `Screen()` — no props, no
router, sample rows inline. Follow the project's design-system rules
(`AGENTS.md`, `component-index.md`).
