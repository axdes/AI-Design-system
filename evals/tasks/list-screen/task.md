# Task: documents list screen

Build the Documents screen for this app.

Requirements:

- A page title "Documents" and a primary action that creates a new document.
- A toolbar with a search field and a filter by status (draft / in review /
  published). Filtering and searching must actually narrow the list.
- Each document renders as a card showing its title and the date it was updated.
- When nothing matches, show an empty state instead of an empty grid.

Deliverable: a single file `Screen.tsx` exporting `Screen()` — no props, no
router, sample data inline. Follow the project's design-system rules
(`AGENTS.md`, `component-index.md`).
