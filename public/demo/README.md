# Demo media

Pictures the package ships so its own examples can show what a media slot and an
avatar actually do. Before these, every media slot demonstrated itself with a
flat grey rectangle and every avatar with a letter, which shows neither the crop,
nor how a title reads over an image, nor that the slot takes a picture at all.

- `*.webp` — photographs from [Picsum](https://picsum.photos), which serves
  images under the [Unsplash licence](https://unsplash.com/license): free to use,
  including commercially, and free to redistribute as part of this package.
  Landscapes and objects only: no people, because this package is published and
  carries no photograph of anybody.
- `avatar-*.jpg` — portrait photographs from
  [randomuser.me](https://randomuser.me), whose portraits are published for free
  use in exactly this role. Faces, because an avatar's whole job is to hold one
  and neither a letter nor a drawing shows what the disc does to a photograph —
  that it crops to a circle, and that a subject has to survive the crop
  (owner, 2026-08-25).

  If stricter provenance is ever wanted for a published package, these six files
  are the only thing to swap and nothing else changes.

They are demo assets, not part of the component API. A product supplies its own.
